Sobre o site

O CodeMaxterX é uma plataforma criada para aprender programação, testar projetos e desenvolver habilidades como um verdadeiro hacker.

Funcionalidades

  • 🔐 Sistema de login (admin e usuário)
  • 💬 Chat entre usuários
  • 🎮 Mini jogos
  • 📊 Barra de habilidades

Objetivo

Este site foi criado para evoluir no mundo da programação, criar projetos reais e desenvolver novas ideias.
