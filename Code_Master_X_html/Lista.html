Lista de coisas para estudar

Esta é uma lista de coisas que você pode estudar para se tornar um mestre da codificação!
Explore os tópicos abaixo e comece a aprender hoje mesmo!


🧑‍💻Programação web(essencial)

    🟢 Nivel iniciante

  1. HTML(estrutyra de sites)
  2. CSS(design e layout)
  3. JavaScript(interatividade e lógica)

🟢 Fundamentos importantes

  1. Como funciona a internet (HTTP,navergador)
  2. DOM(manipular elementos da página)
  3. Eventos(click,teclado, mouse)
  4. Responsividade(site em telemovel)
  5. Flesbox e Grid (layosts mordernos)

🟢JavaScript avançado

  1. Funções
  2. Arrays e objetos
  3. Promises e async/await
  4. Fetch API(buscar dados da internet 🟢)
  5. LocalStorage(guardar dadosno navegador)

🟢Ferramentas de Dev

  1. Git(controlo de versões)
  2. GitHub(guardar projetos online)
  3. VS Code(editor de código)
  4. DevTools do navegador

🟢Frontend proficional

  1. Framework: React(muitoimportante)
  2. Componentesreutilizáveis
  3. Estado(estate)
  4. UI/UX(interfaces bonitas)

🟢Backend (para sites completos)

  1. Node.js
  2. Express.js
  3. APIs(criar e usar)
  4. Autenticação(login e senha🔐)

🔴Banco de dados

  1. Firebase(mais fácil para começar)
  2. ou MongoDB/MySQL

🔴Projetosque você pode fazer

  1. Calculadora
  2. To-do list
  3. Jogo simples
  4. Site com login
  5. Portifólio pessoal
  6. API com dados reais

🔴Extra (te destaca dos outros)

  1. Animações(CSS/JS)
  2. SEO (aparecer no google)
  3. Performance(site rápido ⚡)
